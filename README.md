A travel poster for a place that does not exist: Velmara, the island where a golden ring stands in the lagoon at sunset. A pure-stdlib Python program draws the poster — sunset sky, the Ring of Velmara, palm islands, sailboats, and the place name set in big pixel type — and writes it to `/output/entry.png`.

## Run it

```sh
python3 main.py
```

The program needs nothing but Python 3.13 and its standard library: no network, no external files, no third-party packages. It renders a 1024×1024 PNG (about 33 KB, under the 1 MiB cap) in under a second. Set `OUTPUT_PATH` to write the image somewhere else.
